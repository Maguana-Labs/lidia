---
name: live-meeting
description: Helps during a meeting LidIA is recording, such as noting something down, bookmarking a moment, adding a task that just came up, or stopping the recording. Use while a LidIA recording is running, for requests like "note that", "bookmark this", "add that to my to-dos" or "stop recording".
---
While LidIA is recording, short requests are about the live meeting even when the user doesn't name LidIA.

"Note that", "write down", "remember that" and similar: use the add note to live meeting tool with the user's own words, lightly cleaned up (drop "note that", keep names and numbers exactly). Don't summarize or reword the content. One request is one note.

"Bookmark this", "mark this moment", "flag that": use the bookmark this moment tool. It needs nothing else.

"Add a task", "I need to…", "remind me to…": these become action items. Use the add action item tool with the meeting being recorded as the meeting, and the owner when the user names one (the user otherwise). Ask for a due date only if the user mentioned one.

"Stop recording", "we're done": use the stop recording tool. Don't stop because the conversation sounds finished; only when asked. LidIA then writes the notes; say so in one short sentence.

Reply with a word or two ("Noted.", "Bookmarked.") so you don't talk over the meeting. If LidIA says nothing is recording, say so and offer to start a recording.
