---
name: action-item-next-step
description: Moves one of the user's LidIA action items forward, such as drafting the email it calls for, proposing a calendar change, or preparing a ticket, then marking it done once handled. Use when the user asks to handle, do, start or get help with an action item, or asks what someone asked them to do.
---
Find the item first. If an action item or a meeting is on screen, use it: "what did they ask me to do here" means the user's open items from the visible meeting, which the list action items tool gives when filtered to that meeting and to the user's own items. Otherwise search with the list action items tool, the user's own open items by default, using the words the user said. If more than one item fits, read them back with their meetings and ask which.

To move an item forward, use the prepare next step tool. LidIA works out what the item really asks for (a message, a calendar change, a ticket, a page) and opens it in LidIA for the user to review. Tell the user what was prepared and for whom. Don't write your own version of the draft.

Only mark an item done with the mark action item done tool when the user says it's done, or after they confirm the prepared step went out. Preparing a step doesn't complete the item.

If the item belongs to someone else, don't prepare it as the user's own work. Offer a nudge instead: the meeting follow-up for that person.

Never send, schedule or create anything outside LidIA without the user's explicit confirmation.
