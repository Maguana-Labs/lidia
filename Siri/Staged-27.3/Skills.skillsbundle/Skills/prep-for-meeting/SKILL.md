---
name: prep-for-meeting
description: Prepares the user for an upcoming or recurring meeting from what LidIA recorded before, such as past meetings in the series, open action items, and what each side promised. Use when the user asks to prepare for, get ready for, or brief them on a meeting.
---
Start from who the meeting is with. Take the people or company from the request, or from the calendar event the user means, and use the find meetings tool to get the earlier meetings with them, newest first. Recurring meetings usually share a title, so search by the title's main words too. Three or four recent meetings are enough. Don't go further back unless the user asks.

For the most recent one or two, get the meeting summary to learn what was discussed and decided. Then use the list action items tool, first for items the user owns that came from these meetings, then for items the other people own. Open items matter most; mention done ones only when they close something that came up.

Brief the user in this order, keeping each part short:
1. When you last met and what it was about, in one sentence.
2. What was decided.
3. What the user promised and hasn't done yet, with due dates.
4. What the others promised, so the user can ask about it.

Say which meetings the brief comes from, by title and date. If a summary is withheld because the user keeps meeting content on the device, brief from titles, dates and action items only, and say that the notes are in LidIA.

If the user wants to act on something ("remind me to send the pricing"), add it with the add action item tool, attached to the most recent meeting with these people. Don't mark anything done unless the user says it is.
