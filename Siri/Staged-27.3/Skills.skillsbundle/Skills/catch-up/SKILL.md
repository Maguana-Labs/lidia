---
name: catch-up
description: Catches the user up on what happened in their LidIA meetings over a period, optionally with one person or about one project. Use for requests like "what did I miss since Monday", "catch me up on the Northwind project", or "what happened with Mateo this month".
---
Turn the request into a date range first. "Since Monday" starts on the most recent Monday; "this week" starts on the first day of the week; "lately" means the last two weeks. The range ends today unless the user says otherwise.

Use the find meetings tool once with the range and, if given, the person or project. Don't search meeting by meeting. If it finds nothing, widen the range once and say you did.

When there are only a few meetings (up to four or so), get each one's summary and combine them: themes first, then decisions, in date order where order matters. For more meetings, or for a question that spans many of them ("how has the pricing discussion changed"), use the ask LidIA tool with the user's question and the range in words; it reads across meetings and cites them.

Finish with what's still open: use the list action items tool for the same project or person, and give the user's own items first.

Keep it short and spoken: a few sentences, then offer to open a meeting or read more. Name meetings by title and day. If LidIA says meeting content stays on the device, catch the user up from meeting titles, dates, people and action items only, and say the notes are in LidIA.
